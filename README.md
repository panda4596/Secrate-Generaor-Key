# Secure Secret Key Generator

A small Python CLI project that generates random secret keys and checks their strength.

This project was built as a hands-on Python practice project, focusing on functions, loops, conditions, string methods, user input, and the `secrets` module.

## Features

- Generates random secret keys
- Supports user-defined key length
- Includes uppercase letters
- Includes lowercase letters
- Includes numbers
- Includes special characters
- Checks the generated key strength
- Allows generating multiple keys in one session
- Uses Python's `secrets` module for security-sensitive randomness

## Concepts Used

- Python Functions
- `for` loops
- `while` loops
- `if / elif / else`
- User input
- String concatenation
- String methods
- Boolean variables
- `return`
- Python `secrets` module

Make sure Python is installed on your system.

python secret_generator.py
